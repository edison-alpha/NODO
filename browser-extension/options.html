Connection

In nodo, open Settings → Integrations, turn on Accept links from the extension, and copy the pairing token.

Features

Take over browser downloads Downloads Chrome starts on its own go to nodo instead.
How it works

Right-click only sees a link's address, which on many sites isn't the file. With this on, nodo gets the final address once Chrome has followed every redirect.

The link is handed over first and the browser's copy cancelled only after nodo accepts it — if nodo is closed, Chrome simply finishes the download. Chrome shows this permission as access to all your downloads.
Include site cookies Makes downloads that need a login work instead of failing with 403.
What this allows

Chrome lets an extension with this permission read all your cookies. nodo only reads them for the site of a link you send, at the moment you send it, and only to the app on this computer, which keeps them in memory and never writes them to disk.
